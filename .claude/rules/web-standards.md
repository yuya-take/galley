# Web (Frontend) Standards

## Tech Stack

- **画面**: Topcoat（サーバー描画）。動きは `$()` 式や HTMX 連携で付ける
- SPA フレームワーク（React など）とビルドツール（npm など）は使わない。バイナリ1つで配布するため
- Topcoat は実験段階なので、Topcoat の型や処理は `crates/web` の外に出さない（`.claude/rules/clean-architecture.md`）

## 外部リソース

- 外部 CDN、Google Fonts などの外部フォント・スクリプト・画像を読み込まない。社内ネットワークで、インターネットに出られない環境でも動かすため
- フォント・アイコン・スクリプトはリポジトリに同梱し、バイナリに埋め込んで自前で配信する

## 資料の埋め込み

- 資料は必ず資料配信のオリジン（既定は :8081）の URL を iframe で埋め込む。アプリのページに資料の HTML を直接差し込まない
- iframe の sandbox は `allow-scripts` だけにする

## 状態を変える操作

- POST などは、独自ヘッダー付きの JSON で送る（サーバーの CSRF 対策の前提）
- 更新者名はブラウザに保存した値を送る。未設定なら先に名前を聞く

## 見た目（中世の航海と写本）

画面の骨組みと言葉づかいは使いやすさを優先し、中世らしさは配色・ロゴ・見出しの書体・細い金の飾りで出す。

| トークン | 用途 |
|---------|------|
| ラピスラズリの紺 | サイドバー |
| 羊皮紙色 | 本文の背景 |
| 墨色 | 文字 |
| 深紅 | 主な操作 |
| 金 | 飾り、版の表記 |

- 色は CSS 変数（デザイントークン）で定義し、個別の要素に色を直書きしない
- 書体: ロゴは UnifrakturMaguntia、見出しと資料名は Zen Old Mincho、本文と操作部品は Noto Sans JP

## 言葉づかい

- 版は「第5版」
- ボタンは「開く」「リンクをコピー」「この版に戻す」のような普通の言葉にする
- コードの用語との対応は `.claude/rules/naming-conventions.md` の用語表に従う

## アクセシビリティ

- 操作できる要素はボタン・リンクなど適切な要素にし、キーボードで操作できる
- アイコンだけのボタンには `aria-label` を付ける
- 羊皮紙色の背景と文字のコントラストは WCAG AA（4.5:1）以上
